# ETerm 默认值

首次启动与「恢复默认设置」使用的基线。默认值以代码为准，本文件是复核后的快照；改动默认值时同步更新这里。

## 窗口

| 项 | 默认 | 来源 |
| --- | --- | --- |
| 尺寸 | 1080 × 720 | `src/shared/window-bounds.ts` |
| 位置 | 恢复上次位置；与显示器无交集时回当前鼠标所在屏幕居中 | `window-state.json` |
| 最大化 | 记住上次状态 | `window-state.json` |

## 面板布局

| 停靠区 | 默认面板 | 尺寸 | 可调范围 |
| --- | --- | --- | --- |
| 左 | 会话树 | 220px | 220–360 |
| 右 | 文件 | 300px | 260–450 |
| 底 | 传输队列 | 160px | 120–360 |

系统资源面板默认不打开，用 ⌘⇧M 或标签栏图标切换。

## 终端外观

| 项 | 默认 | 范围 |
| --- | --- | --- |

| 字体 | SF Mono（回退 Menlo → Monaco） | SF Mono / Menlo / Monaco / 系统等宽 |
| 行高 | 1.2 | 1.0–1.6 |

| 右键 | 粘贴；有选中内容时先复制 | 粘贴 / 菜单 / 关闭 |

## 首次启动

- 无连接且未引导时，主区展示引导卡：新建连接 / 本地终端 / 设置 / 不再显示。
- 关闭引导或执行任一动作后写 `ui.onboarded = true`，之后只保留简洁空态。
- 「恢复默认设置」会把 `ui.onboarded` 一并重置，引导会再出现一次。
