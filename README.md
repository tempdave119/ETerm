# ETerm

## 项目简介

macOS 优先的 SSH / SFTP 工作台：连上机器、在终端里干活、顺手把文件搬来搬去，全部在同一个窗口里完成，不跳设置页。单人自用项目。

## 目标

- 日常七步（找机器、连接、看状态、传文件、开多个终端、调布局、改配置）全程不离开主窗口。
- 当前进度：P0–P4 全部完成，v0.1.0–v0.9.1 均已发布；M3 日用验收通过（已日常使用并基本替代 WindTerm / Tabby）；v0.9.1 为上游故障可诊断（崩溃兜底）与供应链加固（Electron 版本锁定、依赖审计、SSH 算法白名单）；v0.9.0 为全量代码审查修复与响应速度优化。

## 核心功能

- 本地终端：多标签、真彩色、宽字符、输入法、鼠标；右键可配（粘贴 / 右键菜单 / 关闭），⌘C / ⌘V 可用；默认 shell 可选系统默认 / zsh / bash / sh / 自定义，标签栏 `+` 一键使用默认，`▾` 菜单可临时换 shell 或输入自定义命令，均只影响本次新建；⌘F 在终端内搜索滚回内容；字体（SF Mono / Menlo / Monaco / 系统等宽）、行高、光标样式与闪烁、滚回缓冲均可在设置里调；左侧 gutter 默认显示每行时间戳与行号（可分别关闭），全屏应用自动隐藏。
- SSH 连接：会话树（分组可新建 / 重命名 / 删除）、密码 / 私钥 / agent、主机指纹确认、断线错误归一、经由跳板机（可链式）、HTTP / SOCKS5 代理（支持用户名密码认证）、可配保活间隔与重试次数；链路断开按 1 / 2 / 4 秒退避自动重连（最多 3 次）；连接表单 640×540、字段成对两列（名称 / 分组、协议 / 认证、主机 / 端口、用户名 / 密码、跳板 / 代理），备注为多行文本框且可选。
- 文件面板：名称 / 大小 / 日期 / 权限四列，列头可排序，工具栏可隐藏点文件；可新建文件夹、重命名、删除文件（目录删除后续支持）；侧栏变窄时依次隐藏权限与日期，名称列始终保留；支持拖拽上传、多文件选择、目录递归下载与拖拽上传。
- 传输队列：上传 / 下载（多文件、目录递归）、进度、暂停 / 恢复、取消、失败重试；上传与下载都先写同目录临时文件，成功后替换目标，取消或失败不留半截文件。
- 端口转发：本地 `-L` 与远程 `-R`，按会话管理，关闭会话即释放。
- 扩展：放进用户数据目录即装载，协议与表单字段由扩展 manifest 提供；宿主支持 `boolean` 字段与 `optionsSource` 动态选项。串口样例已升级为可用能力：设备枚举（cu 优先）、波特率 / 数据位 / 停止位 / 校验 / 流控、回车发送 CR / LF / CRLF、打开时设 DTR / RTS；Telnet 样例支持最小 IAC 协商（NAWS / TTYPE / SGA）与明文会话。
- 插件：设置里有独立的「插件」分类；总开关默认关闭，打开后才会加载插件能力并允许安装、启停与卸载；插件用于补充 ETerm 不内置的能力（如 S3），面板 / 命令 / 主题扩展点已就绪，规范见 `docs/plugins.md`；示例插件 `examples/plugins/s3-browser/`（手写 SigV4，无第三方依赖）。
- 分屏：左右 / 上下分屏，每个 pane 独立会话，最多 4 格；分隔条可拖拽，比例按连接记忆。
- 设置：标签栏齿轮或 ⌘, 打开；左侧分类导航（外观 / 终端 / 连接 / 扩展 / 插件 / 传输 / 快捷键 / 面板布局），710px 两栏、高度固定不随分类跳变，标题栏可拖动；config 走草稿——字号 / 字体 / 行高 / 光标 / 主题 / 密度改完即时预览，取消回滚，保存才写盘；「恢复默认设置」与「恢复默认布局」分开，均需二次点击确认。
- 首次启动：无连接且未引导过时，主区展示引导卡（新建连接 / 本地终端 / 设置 / 不再显示）；关闭或执行任一动作后不再出现，恢复默认设置会重新触发一次。
- 窗口：默认 1080×720，记住上次尺寸 / 位置 / 最大化状态；外接屏拔掉后回当前屏居中；「窗口 → 重置窗口大小」可恢复默认。
- 快捷键：设置面板「快捷键」分类查看与修改全部命令键位，支持录制、解绑、恢复默认；冲突行内提示且阻止保存；系统保留键不可绑定。
- 语言：界面、错误、菜单与托盘支持简体中文 / English，默认跟随系统（中文系统中文，其他语言英文）；不重启切换，源码注释与文档不翻。
- 应用菜单与托盘：标准 macOS 菜单（应用 / 文件 / 编辑 / 视图 / 窗口 / 帮助），快捷键提示跟着用户改键同步；帮助菜单可打开配置目录；菜单栏托盘图标提供显示主窗口 / 新建终端 / 新建连接 / 退出，关窗后可从托盘唤回。
- 边界层：会话 / 执行 / 文件 / 传输 / 转发五个资源端口，能力按会话发现。
- 错误态：统一三段式（人话 → 下一步 → 折叠详情），覆盖连接、文件、传输与空态；错误矩阵见 `docs/error-matrix.md`。
- 设计系统：token 清单与控件五态见 `docs/design-tokens.md`；发行版默认值（窗口 / 布局 / 终端外观 / 快捷键 / 首次启动）见 `docs/defaults.md`。
- 运行底座：Electron 依赖面、上游风险传导、版本跟进策略与 Tauri / 原生迁移评估见 `docs/electron-runtime.md`。
- 命令面板：⌘K 搜索并执行命令；快捷键与命令面板共用一份命令注册表。
- 系统资源：本机 CPU / 内存 / 负载 / 核数 / 运行时间 / 主机名 / 根分区 / 进程 Top5 每秒采样；活动 SSH 会话有 exec 时自动切到远端（2 秒采样，展示连接名、`user@host:port`、主机名、运行时间、主要文件系统与进程 Top5），面板用标题和徽标标明「本机 / 远端」；进程 Top5 支持内存 / CPU 切换，选择写入配置、重启保留。⌘⇧M 或标签栏图标切换。
- 面板布局：会话 / 文件 / 系统资源 / 传输队列可在左 / 右 / 底停靠区之间自由移动，同一区内多个面板可拖分隔改比例，齿轮菜单「上移 / 下移」调区内顺序且比例跟面板走；左栏 220–360px、右栏 260–450px、底栏 120–360px 均可拖（默认 220 / 300 / 160）且保证工作区至少 320px，入口为设置面板「面板布局」分区或面板头部齿轮，位置、比例与尺寸重启后保持。数据结构与扩展步骤见 `docs/panels.md`。
- 主题：深 / 浅 / 跟随系统三档，设置面板切换即时生效，终端调色板跟随；支持外部主题（`<用户数据目录>/themes/*.json`，颜色 token + xterm 调色板，校验后加载，缺失回退系统主题），示例见 `examples/themes/nord.json`。
- 后续：v0.9.1 已发布；插件体系（F-57～F-64）与示例插件随包（F-68）闭环：独立分类与开关、面板 / 命令 / 主题扩展点、S3 样例一键安装。待办见 `_pm/track/roadmap.md`。不做：自动更新、`~/.ssh/config` 导入、WebDAV / 容器 exec 组件、跨会话续传。

## 快速上手

```bash
npm install   # postinstall 会补齐 node-pty 的 spawn-helper 执行位
npm run dev
```

窗口打开后点「新建连接」填主机信息，保存并连接后会弹一次主机指纹确认；也可以按 `⌘T` 直接打开本地终端，`⌘K` 打开命令面板，`⌘⇧M` 看本机资源。

扩展：设置 →「扩展」→「安装示例组件」，把串口 / Telnet 示例复制到用户数据目录，重启后新建连接里会出现对应协议；已安装的示例可二次确认后卸载，重启生效。也可以手动把扩展目录放进 `<用户数据目录>/components/`；完整字段与入口契约见 `docs/components.md`。插件（带面板 / 命令 / 主题）与扩展分目录存放，规范见 `docs/plugins.md`。

外部主题：把 `examples/themes/nord.json` 复制到 `<用户数据目录>/themes/`，在设置「外观」里点「刷新主题」后选择；格式与校验见 `docs/design-tokens.md`。

## 使用方式

| 命令                | 用途                           |
| ------------------- | ------------------------------ |
| `npm run dev`       | 启动 Vite + Electron           |
| `npm test`          | 跑单元测试（`node --test`）    |
| `npm run typecheck` | 类型检查                       |
| `npm run build`     | 构建到 `dist/`                 |
| `npm run smoke`     | 启动应用、用 CDP 验证终端可用  |
| `npm run ssh-smoke` | 模拟 SSH 主机跑通连接与指纹确认 |
| `npm run icon:tray` | 从 `assets/trayTemplate.svg` 生成托盘模板图（16 / 32） |
| `npm run pack`      | 构建并打包成 `release/mac/ETerm.app`（不签名） |
| `npm run dist`      | 构建并出 macOS dmg（`release/ETerm-0.5.0-<arch>.dmg`） |
| `npm run postinstall` | 手动补齐 node-pty spawn-helper 执行位 |

架构与契约见 `_pm/plan/design.md`；分期与进度见 `_pm/track/`。

## 打包

```bash
npm run dist   # 本地出包：release/ETerm-<version>-<arch>.dmg
```

- 发布走 CI：打 `v*` tag 后 GitHub Actions 分别用 `macos-15-intel` 与 `macos-15` 构建 x64 / arm64，并自动创建 Release。
- 未签名（`identity: null`）：首次打开需右键 → 打开，或在「系统设置 → 隐私与安全性」里放行。
- 图标：`assets/icon.svg` 按 macOS 网格（1024 画布 / 824 内容 / 185 圆角）设计，`npm run icon` 生成 `icon.png` 与 16–1024 全套 `icon.icns`；打包经 `mac.icon` 接入，dev 模式用 `app.dock.setIcon` 显示同一图标。
- arm64 产物需在 Apple Silicon 机器上构建；CI 已覆盖双架构，本地构建仅出当前机器架构。
